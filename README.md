# FarmOne Flutter app

FarmOne is a native Flutter mobile app for farmers: listings, marketplace discovery, order management and collection logistics.

## Run it

Install the Flutter SDK, then from this folder:

```bash
flutter create .
flutter pub get
flutter run
```

`flutter create .` generates the Android/iOS platform folders and does not replace the `lib/main.dart` app code. Use a connected Android device or select Chrome for development preview.

## What is implemented

- Native Material 3 mobile interface and bottom navigation
- Farmer dashboard and live produce listings
- Marketplace catalogue and listing form
- Working accept/decline order workflow
- Consolidated pickup route with savings-focused logistics details
